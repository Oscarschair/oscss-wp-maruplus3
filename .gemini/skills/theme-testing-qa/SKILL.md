# Theme Testing and QA

This skill defines the standards for testing and ensuring the quality of the `oscss-wp-maruplus3` theme.

## Testing Areas

### 1. Visual Assurance
- **Cross-Browser Compatibility**: Verifying that the theme renders correctly in Chrome, Firefox, Safari, and Edge.
- **Responsive Testing**: Using browser dev tools and real devices to ensure layouts adapt to all screen sizes.

### 2. Functional Testing
- **Navigation and Links**: Ensuring all menu items, CTA buttons, and internal links function correctly.
- **Forms**: Testing contact forms for proper validation and successful submission.
- **Custom Post Types**: Verifying that CPT-specific templates correctly display data and filter appropriately.

### 3. Performance & SEO
- **PageSpeed Insights**: Analyzing loading times and optimizing where necessary.
- **Accessibility (A11y)**: Ensuring semantic HTML and keyboard navigability.
- **SEO Ready**: Verifying metadata, heading structures, and schema markup.

## Best Practices
- **Browser Tools**: Consistently using Lighthouse or other auditing tools.
- **Edge Cases**: Testing with extreme content scenarios (e.g., very long titles or no content).
- **Error Handling**: Verifying that the theme handles missing data or invalid inputs gracefully (e.g., `404.php`).
